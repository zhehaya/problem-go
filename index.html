连接设置

Codeforces 禁止自己的页面被嵌入，也不给 HTML 页面返回跨域响应头，所以在普通浏览器里必须靠代理转发题面。

最稳的用法（不需要任何代理）：用 VS Code 内置浏览器打开本文件 —— 在该浏览器面板里执行命令 Simple Browser: Show 并打开本文件即可。 内置浏览器不受跨域限制（实测可直接读取 codeforces.com，200 / 60KB），题面约 1 秒就出来。

用普通 Chrome / Edge 打开时直连会被拦掉，程序会自动改用下面的公共代理；公共代理经常被限流， 若都失败，可填入自己的代理地址（含 {url} 时会自动 URL 编码），或用下方的自建中继。

真实请求一次，约 20 秒
公共代理都不通？30 秒自建一个中继（推荐，之后一劳永逸）

实测：本机可以直连 Codeforces 拿到完整题面（HTTP 200），之所以抓不到，只是因为浏览器不允许网页跨域读取，必须有一层转发。 公共代理随时会被限流或下线，自己跑一个最稳 —— 只用 Python 标准库，不需要装任何依赖。

  1. 点下面的「下载 proxy.py」（或点「复制代码」自己存成 proxy.py）
  2. 在该文件所在目录执行 python proxy.py
  3. 上面的输入框填 http://127.0.0.1:8787/?url=，点「保存」
